# Website fonts

Locally hosted Latin subsets from Google Fonts, downloaded on 2026-09-11.

- Source Serif 4: regular and italic variable web fonts, weights 400–700 and optical sizes 8–60.
- Source Sans 3: regular variable web font, weights 400–700.

Source Serif 4: https://github.com/adobe-fonts/source-serif
Source Sans 3: https://github.com/adobe-fonts/source-sans

Both families use the SIL Open Font License 1.1. The corresponding license
files are included in this directory. Characters outside each font's Latin
coverage use the system fallback stack in styles.css.
